# Interview notes

**Homepage:** https://soham874.github.io/interview-notes/

- **Notes**: every Markdown file inside a folder (such as `Java_SpringBoot/`) is listed on the homepage, grouped by folder, with a search across titles, sections and text. A note opens in a reader with the rest of its folder in a sidebar, a table of contents, and previous/next links (or the ← → keys). Diagrams are `` ```mermaid `` code blocks: the reader draws them in the site's light or dark colours, and GitHub draws them too.
- **Visualizers**: every `.html` page in `Visualizers/` is listed on the homepage.

New files and new folders show up after the next GitHub Pages build, and every push to `main` triggers one. Top-level Markdown files (this README and the study plans) and PDFs stay off the site; `_config.yml` lists them.
